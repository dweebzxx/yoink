# yoink! App Asset Palette
See `/yoink/brand/asset_color_system.md` for further color choices like text.

For yoink!, use a **Periwinkle-led palette with Burnt Orange contrast and warm neutral depth**.

| Role                   | Color            |       Hex | Use                                     |
| ---------------------- | ---------------- | --------: | --------------------------------------- |
| **Main color**         | Periwinkle 700   | `#4C62A8` | Dominant icon field / primary object    |
| **Deep shadow**        | Periwinkle 900   | `#263060` | Depth, lower edges, dimensional shading |
| **Highlight**          | Periwinkle 300   | `#9AAAD8` | Lit edges, soft dimensional highlights  |
| **Primary contrast**   | Burnt Orange 700 | `#8F4218` | Main contrasting object/detail          |
| **Bright warm accent** | Burnt Orange 300 | `#D4906A` | Highlight on orange elements            |
| **Small accent**       | Warm Amber 500   | `#D4A030` | Tiny emphasis details only              |
| **Light neutral**      | Canvas           | `#FAF7F2` | Paper/light surfaces                    |
| **Dark neutral**       | Text Primary     | `#1A1E22` | Deepest details/shadows                 |

### Core combination

The icon should visually read mostly as:

**Periwinkle → Burnt Orange → Warm Off-White**

with the darker/lighter stops used for dimensionality rather than introducing additional hues.

A good approximate distribution would be:

**55–65% Periwinkle**
**15–25% Burnt Orange**
**10–20% Warm Off-White**
**<5% Amber**
